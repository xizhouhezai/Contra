## 1. 全批通用规则

### 1.1 风格锚点

沿用现有 art-style.md 的 Riso 技术手册风格：

```text
二次元立绘 + 硬边工业感 + 限量色（纸色 #f4f1ea / 墨 #1a1a1a / 朱 #d6452c / 青 #1f6f6b / 赭 #c8901f）
零圆角，粗描边，网点渐变，印刷错位感
```

### 1.2 全局负向词（每个提示词都追加）

```text
no photorealistic, no 3D render, no glossy plastic, no soft blur,
no gradient mesh, no anime moe eyes on mechanical parts,
no text, no watermark, no border, no drop shadow on transparent area
```

### 1.3 输出规格

| 类型 | 尺寸 | 格式 | 背景 |
| --- | --- | --- | --- |
| 敌人（侧视） | 64×64 每帧 | webp | 透明 |
| 背景层 | 1920×540 | webp | 不透明 |
| 房间地形套件 | 256×256 模块 | webp | 透明 |
| 中段小 Boss | 128×128 每帧 | webp | 透明 |

## 3. 新敌人（4 种）

幕 I 主题：码头、锈铁、栈道、审计厅。敌人要体现**工业废料 + 数据废料**的混合感。

### 3.1 scrapper · 拾荒者

```text
[主体] 半人高的四足机械拾荒单位，外壳由码头废铁片焊接而成，
       背部挂着一个装满螺丝与齿轮的破布袋
[配色] 主体墨黑 #1a1a1a，锈斑朱红 #d6452c，布袋赭黄 #c8901f
[动作] 4 帧：待机 / 疾走 / 挥爪 / 受击
[特征] 一只眼睛是坏掉的红色指示灯，另一只是正常的青色
[风格] Riso 印刷风，粗黑描边，网点阴影，零圆角
[尺寸] 64×64 每帧，透明背景
[负向] 见 §1.2
```

**用途**：快速接近的骚扰型，血量低，成群出现

### 3.2 crane-hook · 吊钩

```text
[主体] 从上方垂下的重型工业吊钩，钩身挂着半截集装箱残片，
       链条在画面外延伸（不画链条顶端）
[配色] 钩身墨黑 #1a1a1a，锈迹朱红 #d6452c，高光纸色 #f4f1ea
[动作] 3 帧：静止 / 摆动 / 下砸
[特征] 钩尖有不规则的磨损缺口，摆动帧要有速度线
[风格] Riso 印刷风，粗黑描边，网点阴影
[尺寸] 64×128 每帧，透明背景
[负向] 见 §1.2
```

**用途**：悬挂型障碍，周期性下砸，逼迫玩家掌握时机

### 3.3 steam-vent · 蒸汽口

```text
[主体] 地面上的圆形工业管道口，周围一圈铆钉，
       喷出的白色蒸汽呈三层扩散
[配色] 管道墨黑 #1a1a1a，铆钉纸色 #f4f1ea，蒸汽纯白略带青 #1f6f6b
[动作] 4 帧：闭合 / 预警冒气 / 全喷 / 衰退
[特征] 预警帧蒸汽最少，全喷帧蒸汽最高，四帧循环
[风格] Riso 印刷风，网点渐变做蒸汽密度
[尺寸] 96×96 每帧，透明背景
[负向] 见 §1.2
```

**用途**：地形陷阱，需要跳跃或等待

### 3.4 audit-drone · 审计无人机

```text
[主体] 悬浮的小型无人机，机身是卷宗盒造型，
       下方垂着一个发光的扫描镜头
[配色] 机身墨黑 #1a1a1a，扫描光青 #1f6f6b，警示灯朱红 #d6452c
[动作] 4 帧：巡航 / 锁定（镜头变红） / 射击 / 受击
[特征] 锁定帧的红色激光要明显，是给玩家的预警
[风格] Riso 印刷风，粗黑描边，激光用实线不用模糊
[尺寸] 64×64 每帧，透明背景
[负向] 见 §1.2
```

**用途**：远程敌人，锁定后有预警，会被玩家优先击杀

## 4. 背景层（3 张）

幕 I 房间需要的背景层。**不需要重画现有 4 层**，这是为 roguelite 房间新增的。

### 4.1 bg-act1-warehouse-far · 仓库远景

```text
[主体] 码头仓库群的剪影，多层货架与吊车，
       最远处是雾中的海平线和船只轮廓
[配色] 纸色底 #f4f1ea，远景用 30% 墨 #1a1a1a，中景 50%，近景 70%
[层次] 至少 3 层可分离的深度，但输出为单张合成图
[特征] 整体偏冷，雾气用网点密度表现
[风格] Riso 印刷风，无描边（背景层），网点渐变
[尺寸] 1920×540，不透明
[负向] 见 §1.2，另外 no characters, no enemies
```

### 4.2 bg-act1-corridor-mid · 回廊中层

```text
[主体] 锈铁回廊的内部纵深，两侧是管道与阀门，
       顶部有破损的照明灯
[配色] 主色墨黑 #1a1a1a，锈迹朱红 #d6452c，灯光赭黄 #c8901f
[层次] 前中后三层，中间留出玩家活动空间（画面下半部要空）
[特征] 透视指向画面右侧，暗示前进方向
[风格] Riso 印刷风，无描边，网点阴影
[尺寸] 1920×540，不透明
[负向] 见 §1.2，no characters
```

### 4.3 bg-act1-scaffold-sky · 栈道天空

```text
[主体] 高架栈道外的开阔天空，云层压得低，
       下方是模糊的城市轮廓
[配色] 天空用纸色到淡青 #1f6f6b 的网点渐变，城市轮廓 40% 墨
[层次] 纯远景，不要近景细节（近景由地形层负责）
[特征] 整体明亮，与关卡内的深色地形形成对比
[风格] Riso 印刷风，网点渐变，无描边
[尺寸] 1920×540，不透明
[负向] 见 §1.2，no characters, no buildings in foreground
```

## 5. 房间地形套件（6 套）

roguelite 房间需要**可拼接的模块化地形**。每套是一组 9 宫格瓦片 + 装饰件。

### 5.1 tiles-act1-floor · 地面

```text
[主体] 9 宫格地板瓦片：四角 / 四边 / 中心，
       表面是锈蚀的钢板，有排水孔与铆钉
[配色] 钢板墨黑 #1a1a1a，锈迹朱红 #d6452c，边缘高光纸色
[规格] 256×256 的 3×3 网格，每格 85×85，透明背景
[特征] 四边要能与同套其他瓦片无缝拼接，中心格可重复平铺
[风格] Riso 印刷风，粗黑描边（地形需要描边）
[负向] 见 §1.2
```

### 5.2 tiles-act1-wall · 墙面

```text
[主体] 9 宫格墙体瓦片，垂直的工业墙板，
       带检修口与电缆槽
[规格] 256×256 的 3×3 网格，透明背景
[特征] 顶边是平的（承接地板），底边可延伸到画面外
[风格] 同 5.1
[负向] 见 §1.2
```

### 5.3 tiles-act1-platform · 平台

```text
[主体] 单向平台：横向 3 段拼接（左端 / 中段 / 右端），
       厚度约 16px，下方有支撑架
[规格] 384×64（3 段各 128 宽），透明背景
[特征] 玩家可以从下方穿过，所以底面要有明显的可穿过视觉语言（如虚线）
[风格] 同 5.1
[负向] 见 §1.2
```

### 5.4 tiles-act1-props · 装饰件

```text
[主体] 8-12 个可散落的小装饰：木箱、油桶、缆绳盘、
       破损的告示牌、堆叠的货箱、散落的齿轮
[规格] 单个 64×64，一张图里并排 4×3 排列，透明背景
[特征] 每个装饰件独立可切分，风格统一
[风格] 同 5.1
[负向] 见 §1.2
```

### 5.5 tiles-act1-hazard · 危险地形

```text
[主体] 危险地形瓦片：带刺的铁栅、漏电的电缆段、
       塌陷的空洞边缘
[配色] 危险部分用朱红 #d6452c 强调，其他用墨黑
[规格] 3 种各 128×128，并排一张，透明背景
[特征] 危险边缘要有明显的红色警示条纹，不依赖形状区分
[风格] 同 5.1
[负向] 见 §1.2
```

### 5.6 tiles-act1-door · 房间门

```text
[主体] 房间过渡门：关闭态 / 半开态 / 全开态三帧，
       门框是重型工业闸门
[配色] 门框墨黑，状态指示灯青/赭/朱红三色对应开/半/关
[规格] 3 帧各 96×160，并排一张，透明背景
[特征] 状态指示灯的三种颜色必须区分明显，且配有不同形状（圆/方/三角）以满足无障碍要求
[风格] 同 5.1
[负向] 见 §1.2
```

## 6. 中段小 Boss（4 个）

复用现有 BossDirector，每个是 1-2 阶段的轻量 Boss。血量约为关底 Boss 的 25-35%。

### 6.1 miniboss-dock-foreman · 码头工头

```text
[主体] 一点五倍人形的重型机械工头，右手是液压钳，
       左肩扛着一捆钢缆
[配色] 主体墨黑 #1a1a1a，液压钳朱红 #d6452c，钢缆赭黄 #c8901f
[动作] 6 帧：待机 / 行走 / 挥钳 / 冲锋 / 受击 / 倒地
[特征] 体型比普通敌人明显大，轮廓要一眼可辨
[规格] 128×128 每帧，透明背景
[风格] Riso 印刷风，粗黑描边
[负向] 见 §1.2
```

### 6.2 miniboss-pipe-warden · 管廊看守

```text
[主体] 长在管道上的机械触手团，中央是一个阀门造型的核心，
       核心是弱点
[配色] 触手墨黑，核心朱红发光 #d6452c，蒸汽白色
[动作] 6 帧：静止 / 伸展 / 横扫 / 核心暴露 / 受击 / 崩塌
[特征] 核心暴露帧要明显（红光大亮），是给玩家的攻击窗口
[规格] 160×160 每帧，透明背景
[风格] 同 6.1
[负向] 见 §1.2
```

### 6.3 miniboss-scaffold-crane · 栈道吊车

```text
[主体] 迷你化的塔吊造型，吊臂可旋转，吊钩是攻击手段
[配色] 塔吊墨黑，吊臂关节赭黄 #c8901f，警示灯朱红
[动作] 5 帧：待机 / 旋转 / 下砸 / 受击 / 倒塌
[特征] 体型宽扁，占据画面上方
[规格] 192×128 每帧，透明背景
[风格] 同 6.1
[负向] 见 §1.2
```

### 6.4 miniboss-audit-clerk · 审计书记

```text
[主体] 悬浮的巨型卷宗柜，柜门可开合，
       内部是成排发光的档案格
[配色] 柜体墨黑，档案格青 #1f6f6b，柜门边缘朱红
[动作] 5 帧：闭合 / 半开 / 全开（发射） / 受击 / 碎裂
[特征] 开合是主要节奏，闭合时无敌，全开时露出内部
[规格] 144×144 每帧，透明背景
[风格] 同 6.1
[负向] 见 §1.2
```

## 7. 玩法 UI（3 张）

### 7.1 ui-wave-warning · 波次预警

```text
[主体] 屏幕边缘的警告条：左侧竖条 + 箭头，指示敌人从哪边来
[配色] 朱红 #d6452c 主色，纸色 #f4f1ea 底，墨黑描边
[规格] 3 种方向（左/右/上）各 128×64，并排一张，透明
[特征] 不使用颜色单独传达方向，箭头形状本身要清楚
[风格] Riso 印刷风，粗黑描边，零圆角
[负向] 见 §1.2
```

### 7.2 ui-route-map · 路线图

```text
[主体] 小地图样式的房间路线指示：几个方块代表房间，
       连线代表可走路径，当前房间高亮
[配色] 已走墨黑 #1a1a1a，当前朱红 #d6452c，未走 30% 灰
[规格] 256×128，透明
[特征] 房间方块用不同形状区分类型（战斗/宝箱/平台/小 Boss）
[风格] Riso 印刷风，粗黑描边，零圆角
[负向] 见 §1.2
```

### 7.3 ui-room-type-icon · 房间类型图标

```text
[主体] 4 个房间类型图标：战斗（交叉刀）、宝箱（箱）、
       平台（三级台阶）、小 Boss（骷髅）
[配色] 墨黑 #1a1a1a 线条，纸色底
[规格] 4 个各 64×64，2×2 排列，透明
[特征] 形状完全区分，不依赖颜色
[风格] Riso 印刷风，粗黑描边
[负向] 见 §1.2
```

## 8. 交付验收

| 检查项 | 方法 |
| --- | --- |
| 尺寸正确 | 用 PIL 打开检查 size |
| 背景透明 | 检查 alpha 通道存在 |
| 风格一致 | 与现有 enemies/ 同级资产并排目视对比 |
| 命名一致 | 文件名与本文完全一致 |
| 可拼接 | 地形瓦片拼成 3×3 后无缝隙 |
