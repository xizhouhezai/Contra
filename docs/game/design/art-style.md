# 美术风格指南

> 追溯：REQ-GDD-001 · ADR-0004 ｜ 状态：开发参考稿（**发行版须重绘**）

本页是 M4 的美术基准，供内部与外包直接执行。
它定义视觉规则、素材规格与版权边界 —— 三者缺一不可，
因为本项目现阶段使用的是**社区二创素材作为参考**，不是可发行的成品。

## 1. 版权边界（先读这一节）

仓库内 `assets/` 下的全部图片**仅用于开发阶段的视觉参考与页面展示**，
**不得直接进入发行产物**。分三档风险：

| 来源 | 许可证 | 可否商用 | 处理方式 |
| --- | --- | --- | --- |
| ZipZipPipe（`zipzippipe/`） | CC BY-NC-SA 4.0 | **否** | 必须重绘或取得授权 |
| 梗鲸表情包（`official/meme-*/`） | 各作者不一，多为未声明 | **否** | 必须重绘 |
| 豆包官方（`official/doubao/`） | 字节跳动商标形象 | **否** | 必须重绘 |

结论：**发行版所有角色、敌人、Boss 美术一律从零重绘。**
现行素材的作用是统一「这个角色长什么样」的共识，不是贴图来源。

## 2. 视觉基调

沿用文档站的 Riso 技术手册风格（见[设计语言](/guide/design-language)），
游戏内 UI 与文档站保持同一套视觉语言：

| 项 | 规格 |
| --- | --- |
| 主色 | 朱红 `#d6452c`（警示/强调）、青碧 `#1f6f6b`（信息/冷静） |
| 辅色 | 赭黄 `#c8901f`、墨黑 `#1a1a1a`、纸白 `#f4f1ea` |
| 圆角 | **一律 0** —— 全部直角，这是 Riso 印刷的机械感来源 |
| 描边 | 2px 实线，纯黑，不用渐变阴影 |
| 标题字 | 衬线（Instrument Serif / Georgia） |
| 标签字 | 等宽（IBM Plex Mono / monospace） |
| 颗粒 | 可叠加轻微网点纹理，不叠加则亦可 |

## 3. 素材规格

### 立绘（portraits/）

| 项 | 规格 |
| --- | --- |
| 尺寸 | 900 × 900 以内，长边 900px |
| 格式 | WebP，quality 82 |
| 单张体积 | ≤ 300 KB |
| 背景 | 透明或纯色，不留环境 |
| 构图 | 半身，面部占画面上 1/3 |

### 表情差分

每个角色至少 3 个：**常态 / 受创 / 得意**。
差分只改眉眼与嘴，发型、服装、配饰**不得变动** —— 否则玩家认不出是同一角色。

### 精灵（sprite/，M4 波次2 产出）

| 项 | 规格 |
| --- | --- |
| 尺寸 | 48 × 48 px（角色）、32 × 32 px（杂兵）、96 × 96 px（Boss） |
| 状态 | 待机 / 跑动 / 跳跃 / 受击，各 2~6 帧 |
| 帧序列 | 水平排布，等宽切片 |
| 描边 | 1px 深色轮廓，保证 16px 下仍可辨 |

> 「保留识别特征」指的是角色概念（蓝发+鲸尾），不是复刻具体某张画。

## 7. 交付检查清单

重绘素材入库前逐条核对：

- [ ] 尺寸符合规格，格式为 WebP
- [ ] 单张 ≤ 300 KB
- [ ] 主色取自第 2 节的配色表
- [ ] 直角，无圆角
- [ ] 识别特征（第 4、5 节）已保留
- [ ] 表情差分只改眉眼嘴
- [ ] 附来源与许可证信息
