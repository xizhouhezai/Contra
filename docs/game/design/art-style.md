# 美术风格指南

> 追溯：REQ-GDD-001 · ADR-0004 ｜ 状态：**非商业同人项目（不重绘，直接使用社区素材）**

本页是 M4 的美术基准，供内部与外包直接执行。
它定义视觉规则、素材规格与使用边界 —— 三者缺一不可。

## 1. 使用边界（先读这一节）

**本项目是非商业同人作品，不用于任何形式的商业发行。**
因此直接采用社区二创素材，不重绘。这个决定让素材可用，但**不解除义务** ——
CC BY-NC-SA 的「非商业」条款正因本项目不商用而满足，另两项仍然生效：

| 义务 | 要求 | 本项目如何满足 |
| --- | --- | --- |
| **署名**（BY） | 标明原作者 | 每张素材的来源见 §6 表；游戏内「关于」页需列出 |
| **相同方式共享**（SA） | 改编作品沿用同一协议 | 本项目的角色美术部分整体以 CC BY-NC-SA 4.0 发布 |
| **非商业**（NC） | 不得用于商业目的 | 本项目不商用 —— **这是前提，一旦商业化即失效** |

### 三档来源与各自要求

| 来源 | 许可证 | 商用 | 本项目处理 |
| --- | --- | --- | --- |
| ZipZipPipe（`zipzippipe/`） | CC BY-NC-SA 4.0 | 否 | **直接使用**，署名 + 同协议共享 |
| 梗鲸表情包（`official/meme-*/`） | 各作者不一，多为未声明 | 否 | **直接使用**；未声明者标注来源与「作者未声明许可」 |
| 豆包官方（`official/doubao/`） | 字节跳动商标形象 | 否 | **直接使用**，注明商标归属字节跳动 |
| 音频 / 背景 | CC0（Kenney / Luis Zuno / OpenGameArt） | 是 | 无需义务，已署名 |

> **一旦本项目的性质从「非商业」变为「商业」**（含付费、内购、广告、众筹、
> 商业平台分成发行），上表前两行的授权立即失效，必须重绘或重新取得授权。
> 这个前提必须随项目一起记录，否则半年后没人记得为什么当时能用。

### 无法确认作者的那几张

`unknown-a05-cat-stars.webp`、`unknown-a06-sunflower.webp` 与梗鲸批量图
无法确认原作者。**保留原文件名而不是猜测归属**，并在 §6 如实标注。
如果将来需要严格合规，这几张是第一批要替换的。

## 2. 视觉基调

沿用文档站的 Riso 技术手册风格（见[设计语言](/guide/design-language)），
游戏内 UI 与文档站保持同一套视觉语言：

| 项 | 规格 |
| --- | --- |
| 主色 | 朱红 `#d6452c`（警示/强调）、青碧 `#1f6f6b`（信息/冷静） |
| 辅色 | 赭黄 `#c8901f`、墨黑 `#1a1a1a`、纸白 `#f4f1ea` |
| 圆角 | **一律 0** —— 全部直角，这是 Riso 印刷的机械感来源 |
| 描边 | 2px 实线，纯黑，不用渐变阴影 |
| 标题字 | 衬线（Instrument Serif / Georgia） |
| 标签字 | 等宽（IBM Plex Mono / monospace） |
| 颗粒 | 可叠加轻微网点纹理，不叠加则亦可 |

## 3. 素材规格

### 立绘（portraits/）

| 项 | 规格 |
| --- | --- |
| 尺寸 | 900 × 900 以内，长边 900px |
| 格式 | WebP，quality 82 |
| 单张体积 | ≤ 300 KB |
| 背景 | 透明或纯色，不留环境 |
| 构图 | 半身，面部占画面上 1/3 |

### 表情差分

每个角色至少 3 个：**常态 / 受创 / 得意**。
差分只改眉眼与嘴，发型、服装、配饰**不得变动** —— 否则玩家认不出是同一角色。

### 精灵（sprite/，M4 波次2 产出）

| 项 | 规格 |
| --- | --- |
| 尺寸 | 48 × 48 px（角色）、32 × 32 px（杂兵）、96 × 96 px（Boss） |
| 状态 | 待机 / 跑动 / 跳跃 / 受击，各 2~6 帧 |
| 帧序列 | 水平排布，等宽切片 |
| 描边 | 1px 深色轮廓，保证 16px 下仍可辨 |

### 素材现状（合并说明）

项目不重绘，因此下表是**现状而非待办**。形态 II 两个 Boss 用同一张立绘
加程序化配色偏移表达（暗化 + 转向赤红），这与游戏内「形态切换」的
表现层处理一致，也避免伪造一张不存在的原画。

| 项 | 现状 | 游戏内如何处理 |
| --- | --- | --- |
| Claude 完整立绘 | **只有 Q 版**（梗鲸 28 张全为方形表情图） | 用 Q 版，配方形画框；与 Riso 直角风格反而一致 |
| Claude 改写者 | 无独立素材 | 审计者立绘 + 赤红色调偏移 |
| GPT 涌现 | 无独立素材 | 语料立绘 + 暗化崩解偏移 |
| 表情差分 | 现有素材均为单图 | 六角色各 1 张，不做差分 |
| 豆包立绘 | 官方仅 160×160 头像 | 按原尺寸放大显示，不外插值美化 |

> **不伪造**是这里的底线：宁可用有据可查的 Q 版，也不用 AI 生成一张
> 长得像但不属于任何作者的原画。后者既无法署名，也混淆了素材来源。

## 7. 素材入库检查清单

新增素材前逐条核对：

- [ ] 尺寸符合规格，格式为 WebP
- [ ] 单张 ≤ 300 KB
- [ ] 附来源 URL、作者名、许可证三要素
- [ ] 许可证与「非商业」前提不冲突
- [ ] 无法确认作者的，文件名保持 `unknown-*` 不猜归属
- [ ] 已在 §6 表中登记

> 程序生成的精灵（`sprites/`）由 `scripts` 内的生成逻辑产出，
> 遵循第 2 节配色与直角规则，无第三方版权问题。
