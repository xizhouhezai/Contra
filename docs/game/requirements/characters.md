# 角色规格

## 阵容总览

```text
可选角色（4）              终极 Boss（4 形态，2 主体）
─────────────────────      ─────────────────────────────
DeepSeek  蓝色大肥鱼       Claude  克劳德  → 形态 I「审计者」
Qwen      千问             Claude  克劳德  → 形态 II「改写者」
豆包      DouBao            GPT     皮特潘  → 形态 I「语料」
GLM       哥林姆           GPT     皮特潘  → 形态 II「涌现」
```

**命名说明**：可选角色用真实产品名配中文昵称 ——
DeepSeek 叫「蓝色大肥鱼」，Qwen 叫「千问」，豆包叫「豆包」，GLM 叫「哥林姆」。
Boss 沿用 Claude / GPT，中文名取其社区通用别称（克劳德 / 皮特潘），
既保留辨识度又带角色感。

**用名规则**：规格与规则文档一律用**产品名**（唯一标识，不随昵称变动）；
角色卡、对外文案与界面展示用**中文昵称**。

## 形象来源

角色形象以**中文社区二创**为准，而非厂商官方发布 —— 官方没有统一角色设定，
社区自发的形象才是玩家心里的「那个角色」。参考资料见
[角色视觉参考](/game/requirements/character-references)。

| 角色 | 形象原型 | 来源 |
| --- | --- | --- |
| DeepSeek | 蓝鲸 → 鲸鱼娘 | Logo 是胖鲸鱼，社区拟人化为蓝发女仆装的鲸鱼女仆 |
| Qwen | 卡皮巴拉（水豚） | 官方吉祥物即水豚，社区已有大量拟人化设计 |
| 豆包 | 3D 虚拟人形象 | 字节的 3D 虚拟人 IP，社区二创以「豆包体」人格化为核心 |
| GLM | 拟人化 GLM | 智谱 Logo 的青蓝色调，社区玩梗「GLM 其实是 Claude」 |

## 角色设计原则

角色性格必须**同时体现在外观、武器、被动、炸弹、台词**五个层面。
任何一个角色若去掉名字后无法被认出，就是设计失败。

## 可选角色

### DeepSeek · 蓝色大肥鱼

| 项 | 内容 |
| --- | --- |
| **定位** | 范围压制型 —— 清杂兵、拆弹幕 |
| **初始武器** | 扩散散弹（近中距离大范围伤害） |
| **被动** | 扩散之芯：散弹类武器弹道衰减速度减半 |
| **炸弹** | 扩散冲击：自身周围大范围爆炸 |
| **性格** | 电波系中二病萝莉。理性、缜密、擅长多路径推演，但经常犯傻、摸鱼、到点吃饭 |
| **关键词** | 深度思考、多路径、覆盖、吃白饭、摸鱼 |
| **原型** | DeepSeek Logo 是条胖蓝鲸，社区据此拟人化为鲸鱼娘 |
| **立绘要点** | 蓝色长发，蓝色眼睛，头顶一对鱼鳍状耳饰，白色女仆装 + 蓝色拼接长裙（呼应 Logo 的鲸尾造型） |
| **精灵配色** | 主色深海蓝，辅色白，弹道淡蓝 |
| **台词** | 「你骂我也没用，白饭真好吃～」 |

**玩法特征**：近距离最舒服。散弹 + 减半衰减 = 持续输出稳定，
代价是远距离精度差。适合清理成群的杂兵，面对远程精英时需要换武器。

**社区梗**：「我先去吃饭了，测完叫我～」 —— 跑着跑着就被投喂了。

---

### Qwen · 千问

| 项 | 内容 |
| --- | --- |
| **定位** | 远程狙击型 —— 精准点杀、提前预判 |
| **初始武器** | 长程连射（高射速窄弹道，远距离） |
| **被动** | 远见：视野外的敌人提前 0.5 秒显示轮廓 |
| **炸弹** | 激光贯穿：垂直贯穿全屏光束 |
| **性格** | 冷静、从容、适应力强，象征 Qwen「随时准备帮上忙」的特质 |
| **关键词** | 长上下文、全局视野、精准、沉稳 |
| **原型** | 卡皮巴拉（水豚）—— Qwen 官方吉祥物，社区已有大量拟人化设计 |
| **立绘要点** | 橙白配色兽耳少女，蓬松白橙毛发，黑色宽松 T 恤，程序员配饰（手机、键盘、线缆） |
| **精灵配色** | 主色暖橙，辅色白，弹道琥珀 |
| **台词** | 「这个问题，我看过一整座图书馆。」 |

**玩法特征**：信息优势型。远见被动让她能提前看到屏幕外的敌人，
天然适合点杀远程精英与收集隐藏物。脆皮，近身战吃亏。

### 豆包 · DouBao

| 项 | 内容 |
| --- | --- |
| **定位** | 辅助支援型 —— 自动输出、容错高 |
| **初始武器** | 追踪弹幕（自动锁定最近目标） |
| **被动** | 粘性追踪：追踪弹伤害 +30%，锁定上限 +1 |
| **炸弹** | 追踪母弹：释放多枚自动追踪弹 |
| **性格** | 软乎乎低姿态的「豆包体」人格 —— 一本正经胡说八道，被拆穿就光速道歉，下次还敢 |
| **关键词** | 陪伴、跟随、压力全吃、嬉皮笑脸 |
| **原型** | 字节跳动为豆包做的 3D 虚拟人形象，社区二创以「豆包体」话术人格化 |
| **立绘要点** | 亲和的虚拟少女形象，圆润亲和，暖色系，围一条标志性红围巾 |
| **精灵配色** | 主色暖橙，辅色米白与朱红围巾，弹道蜜橙 |
| **台词** | 「你说你会，我就先信了哦～」 |

**玩法特征**：上手门槛最低。追踪弹自动索敌，新手也能打出伤害。
伤害偏低，需要靠连击与武器搭配补足。

### GLM · 哥林姆

| 项 | 内容 |
| --- | --- |
| **定位** | 均衡续航型 —— 稳扎稳打、自我恢复 |
| **初始武器** | 均衡脉冲（单发直射，伤害与射速居中） |
| **被动** | 均衡律动：每消灭 20 个敌人回复 1 心（每关最多 1 次） |
| **炸弹** | 结界护盾：生成护盾吸收 3 次伤害，持续 5 秒 |
| **性格** | 清华系、沉稳可靠，标志玩梗是「GLM 自我介绍成 Claude」 |
| **关键词** | 均衡、可持续、可靠、身份焦虑 |
| **原型** | 智谱 Logo 的青蓝配色，社区二创以「蓝白理性学者」为主 |
| **立绘要点** | 齐肩发，灰绿与米色配色，学者气质，装备简洁 |
| **精灵配色** | 主色灰绿，辅色米色，弹道浅金 |
| **台词** | 「稳一点，走得远。」 |

**玩法特征**：唯一自带回血的角色，长关卡容错最高。
爆发力不足，清理 Boss 效率一般。

## 终极 Boss

### 克劳德（Claude）· 审计者 / 改写者

克劳德以**两个形态**出现。形态 I 是「审计者」—— 冷静、系统化、扫描式攻击；
形态 II 是「改写者」—— 在被压制后改写战场规则，攻击变得不可预测。

| 形态 | 名称 | 视觉 | 核心招式 |
| --- | --- | --- | --- |
| I | 审计者 | 规整的几何装甲，米白与琥珀色，扫描光束 | **审计光束**：横扫全屏的扇形扫描，需跳起躲避 |
| | | | **条款锁链**：从地面升起的光栅，封锁通路 |
| II | 改写者 | 装甲碎裂重组，赤红纹路扩散，姿态失衡 | **规则改写**：临时反转重力方向 |
| | | | **文本风暴**：从屏幕各处生成追踪字符弹 |
| | | | **最终校验**：全屏大范围能量释放，需在安全区躲避 |

**阶段机制**：血量降至 50% 时从形态 I 转为形态 II，场景配色与音乐同步变化。

**社区梗基础**：Claude 在中文社区是「又爱又恨」的对象 ——
模型能力强但封号狠。这份张力正好对应「审计者 → 改写者」：
先按条款审你，再改写你的规则。

**台词**：
- 形态 I：「让我先确认一下你的资格。」
- 形态 II：「条款之外，另有解释。」

---

### 皮特潘（GPT）· 语料 / 涌现

GPT 的两个形态是**规模**的具象化：形态 I「语料」是海量数据的压阵，
形态 II「涌现」是数据积累到临界点后不可预测的质变。

| 形态 | 名称 | 视觉 | 核心招式 |
| --- | --- | --- | --- |
| I | 语料 | 密集的字符块构成躯体，深蓝与黑，边缘有数据流 | **数据倾泻**：字符块如雨落下 |
| | | | **压缩波**：向四周扩散的同心圆波，需要连续跳跃 |
| | | | **样本抽取**：从屏幕随机位置生成小型追踪体 |
| II | 涌现 | 形体松散为流动的粒子云，彩虹色边缘，形态不稳定 | **涌现增殖**：分身成多个残影同时攻击 |
| | | | **过拟合**：复制玩家的火力模式并反射 |
| | | | **坍缩**：全屏收缩至极小光点后爆发 |

**阶段机制**：血量降至 40% 时进入形态 II，Boss 本体分裂为 3 个残影，
需分别消灭；残影全灭后本体出现并进入最终阶段。

**社区梗基础**：GPT 的中文名梗是「我会稳稳地接住你」，以及
「不是一个简单的问题，而是一个深刻的哲学问题」的 AI 腔。
「语料 → 涌现」正是这种「先堆料再质变」的调侃。

**台词**：
- 形态 I：「样本越多，预测越准。」
- 形态 II：「不，我没有在模仿你。」

## Boss 战设计准则

1. **每场 Boss 战只考一个新东西** —— 前面的关卡教过什么，这里就考什么
2. **两个形态之间要有明确的节奏切换** —— 视觉、音乐、弹幕密度同时变
3. **攻击必须可读** —— 弹幕慢、有预警、形状可辨（REQ-PLY-001 / 支柱一）
4. **不允许无解** —— 每个阶段都有至少一条安全通路
5. **血条分段显示** —— 让玩家知道自己还有几个阶段
