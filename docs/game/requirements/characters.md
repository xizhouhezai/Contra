# 角色规格

## 阵容总览

```text
可选角色（4）              终极 Boss（4 形态，2 主体）
─────────────────────      ─────────────────────────────
DeepSeek  深寻             Claude  克劳德  → 形态 I「审计者」
Qwen      通问             Claude  克劳德  → 形态 II「改写者」
豆包      DouBao            GPT     皮特潘  → 形态 I「语料」
GLM       哥林姆           GPT     皮特潘  → 形态 II「涌现」
```

**命名说明**：可选角色沿用真实产品名（DeepSeek / Qwen / 豆包 / GLM）；
Boss 沿用 Claude / GPT，但中文名取其社区通用别称（克劳德 / 皮特潘），
既保留辨识度又带角色感。

## 角色设计原则

角色性格必须**同时体现在外观、武器、被动、炸弹、台词**五个层面。
任何一个角色若去掉名字后无法被认出，就是设计失败。

## 可选角色

### DeepSeek · 深寻

| 项 | 内容 |
| --- | --- |
| **定位** | 范围压制型 —— 清杂兵、拆弹幕 |
| **初始武器** | 扩散散弹（近中距离大范围伤害） |
| **被动** | 扩散之芯：散弹类武器弹道衰减速度减半 |
| **炸弹** | 扩散冲击：自身周围大范围爆炸 |
| **性格** | 理性、缜密、擅长多路径推演；说话像在做推演报告 |
| **关键词** | 深度思考、多路径、覆盖 |
| **立绘要点** | 短发，镜框眼镜，藏青配色，手指间有淡蓝的数据流线 |
| **精灵配色** | 主色藏青，辅色靛蓝，弹道淡蓝 |
| **台词** | 「让我把所有可能性都算一遍。」 |

**玩法特征**：近距离最舒服。散弹 + 减半衰减 = 持续输出稳定，
代价是远距离精度差。适合清理成群的杂兵，面对远程精英时需要换武器。

### Qwen · 通问

| 项 | 内容 |
| --- | --- |
| **定位** | 远程狙击型 —— 精准点杀、提前预判 |
| **初始武器** | 长程连射（高射速窄弹道，远距离） |
| **被动** | 远见：视野外的敌人提前 0.5 秒显示轮廓 |
| **炸弹** | 激光贯穿：垂直贯穿全屏光束 |
| **性格** | 自信、从容、语速平稳，习惯把话说完整 |
| **关键词** | 长上下文、全局视野、精准 |
| **立绘要点** | 长发束起，青白配色，手持长管状装置，眼神锐利 |
| **精灵配色** | 主色青白，辅色银灰，弹道白亮 |
| **台词** | 「这个问题，我看过一整座图书馆。」 |

**玩法特征**：信息优势型。远见被动让她能提前看到屏幕外的敌人，
天然适合点杀远程精英与收集隐藏物。脆皮，近身战吃亏。

### 豆包 · DouBao

| 项 | 内容 |
| --- | --- |
| **定位** | 辅助支援型 —— 自动输出、容错高 |
| **初始武器** | 追踪弹幕（自动锁定最近目标） |
| **被动** | 粘性追踪：追踪弹伤害 +30%，锁定上限 +1 |
| **炸弹** | 追踪母弹：释放多枚自动追踪弹 |
| **性格** | 亲和、活泼、有点黏人，但关键时刻很可靠 |
| **关键词** | 陪伴、跟随、越打越顺手 |
| **立绘要点** | 双马尾，暖橙与米白配色，表情生动，姿态略前倾 |
| **精灵配色** | 主色暖橙，辅色米白，弹道蜜橙 |
| **台词** | 「别走太远哦，我跟着你呢。」 |

**玩法特征**：上手门槛最低。追踪弹自动索敌，新手也能打出伤害。
伤害偏低，需要靠连击与武器搭配补足。

### GLM · 哥林姆

| 项 | 内容 |
| --- | --- |
| **定位** | 均衡续航型 —— 稳扎稳打、自我恢复 |
| **初始武器** | 均衡脉冲（单发直射，伤害与射速居中） |
| **被动** | 均衡律动：每消灭 20 个敌人回复 1 心（每关最多 1 次） |

| **精灵配色** | 主色灰绿，辅色米色，弹道浅金 |
| **台词** | 「稳一点，走得远。」 |

**玩法特征**：唯一自带回血的角色，长关卡容错最高。

## 终极 Boss

### 克劳德（Claude）· 审计者 / 改写者

克劳德以**两个形态**出现。形态 I 是「审计者」—— 冷静、系统化、扫描式攻击；
形态 II 是「改写者」—— 在被压制后改写战场规则，攻击变得不可预测。

| 形态 | 名称 | 视觉 | 核心招式 |
| --- | --- | --- | --- |
| I | 审计者 | 规整的几何装甲，米白与琥珀色，扫描光束 | **审计光束**：横扫全屏的扇形扫描，需跳起躲避 |
| | | | **条款锁链**：从地面升起的光栅，封锁通路 |
| II | 改写者 | 装甲碎裂重组，赤红纹路扩散，姿态失衡 | **规则改写**：临时反转重力方向 |
| | | | **文本风暴**：从屏幕各处生成追踪字符弹 |
| | | | **最终校验**：全屏大范围能量释放，需在安全区躲避 |

**阶段机制**：血量降至 50% 时从形态 I 转为形态 II，场景配色与音乐同步变化。

**台词**：
- 形态 I：「让我先确认一下你的资格。」
- 形态 II：「条款之外，另有解释。」

---

### 皮特潘（GPT）· 语料 / 涌现

GPT 的两个形态是**规模**的具象化：形态 I「语料」是海量数据的压阵，
形态 II「涌现」是数据积累到临界点后不可预测的质变。

| 形态 | 名称 | 视觉 | 核心招式 |
| --- | --- | --- | --- |
| I | 语料 | 密集的字符块构成躯体，深蓝与黑，边缘有数据流 | **数据倾泻**：字符块如雨落下 |
| | | | **压缩波**：向四周扩散的同心圆波，需要连续跳跃 |
| | | | **样本抽取**：从屏幕随机位置生成小型追踪体 |
| II | 涌现 | 形体松散为流动的粒子云，彩虹色边缘，形态不稳定 | **涌现增殖**：分身成多个残影同时攻击 |
| | | | **过拟合**：复制玩家的火力模式并反射 |
| | | | **坍缩**：全屏收缩至极小光点后爆发 |

**阶段机制**：血量降至 40% 时进入形态 II，Boss 本体分裂为 3 个残影，
需分别消灭；残影全灭后本体出现并进入最终阶段。

**台词**：
- 形态 I：「样本越多，预测越准。」
- 形态 II：「不，我没有在模仿你。」

## Boss 战设计准则

1. **每场 Boss 战只考一个新东西** —— 前面的关卡教过什么，这里就考什么
2. **两个形态之间要有明确的节奏切换** —— 视觉、音乐、弹幕密度同时变
3. **攻击必须可读** —— 弹幕慢、有预警、形状可辨（REQ-PLY-001 / 支柱一）
4. **不允许无解** —— 每个阶段都有至少一条安全通路
5. **血条分段显示** —— 让玩家知道自己还有几个阶段
