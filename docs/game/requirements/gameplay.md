# 玩法规格

## 核心循环

```text
选择角色 → 进入关卡 → 跑轰推进 → 拾取武器与补给
    ↑                                    ↓
重试 ← 阵亡 ← Boss 战 ← 遭遇战 ← 探索地形
```

单关流程：**探索段 → 遭遇战 → 地形谜题 → Boss 战**。
四段的节奏比例约为 40% / 30% / 20% / 10%。

## 操作

### 移动

| 输入 | 行为 |
| --- | --- |
| `←` `→` / A D | 左右移动 |
| `↑` `↓` / W S | 瞄准方向（8 向射击） |
| `空格` / Z | 跳跃 |
| `↓` + 跳跃 | 下蹲（部分地形可进入） |
| `X` / Shift | 炸弹技（每关有次数上限） |
| `Esc` | 暂停菜单 |

### 瞄准与射击

- **8 向自由瞄准**：方向键决定射击方向，**与移动方向解耦**。
  向前跑时按 ↑ 可向后上方射击。
- **持续射击**：按住射击键连发，不需反复点按。
- **不能下蹲射击**（魂斗罗传统），下蹲仅用于钻管道与躲避。

### 跳跃

- 固定跳跃高度与重力，保证弧线可预期。
- 可在下落中微调水平速度（空中控制），但不可二段跳。
- 跳跃是**唯一的平台通行手段**，地形高度差不通过斜坡过渡。

## 战斗

### 生命与伤害

| 项 | 规则 |
| --- | --- |
| 生命单位 | 整数「心」，初始 3 心 |
| 受击 | 失去 1 心，进入约 1.5 秒无敌闪烁 |
| 归零 | 阵亡 |
| 回复 | 补给物可回 1 心，稀有补给回 2 心 |
| 坠落 | 掉落即死，与受击同规则 |

### 得分

| 事件 | 分值 |
| --- | --- |
| 普通敌人 | 100 |
| 精英敌人 | 500 |
| Boss 受击 | 1000 |
| 拾取武器 | 300 |
| 关卡通关 | 5000 + 剩余生命 × 1000 |

**连击**：3 秒内连续击杀累积连击数，连击每 +1 得分倍率 +5%，上限 +100%。
受伤或超时断连。

### 状态效果

| 状态 | 来源 | 效果 |
| --- | --- | --- |
| 无敌闪烁 | 受击后 1.5s | 免伤，角色半透明闪烁 |
| 散射衰减 | 散弹类武器 | 连续射击后弹道变散，需停火恢复 |
| 追踪锁定上限 | 追踪弹 | 同屏最多锁定 N 个目标，超出转普通弹 |
| 记忆印记 | 回溯弹命中 | 目标身上叠加 1 层，满 5 层触发追加伤害 |
| 棱镜分叉 | 棱镜弹击杀 | 弹道分叉一次，最多再命中 1 个目标 |

## 武器系统

### 4 槽共享

所有角色共用 **4 个武器槽**。当前槽位独立计时独立衰减，
拾取新武器替换当前槽，其余槽位保持。

> 采用共享槽位是刻意的：武器切换逻辑统一，保证操作一致性与上手速度。
> 角色差异由**初始武器 + 被动 + 炸弹**承担，而非独立武器栏。

### 武器类型

| 武器 | 行为 | 拾取来源 | 稀有度 |
| --- | --- | --- | --- |
| 脉冲弹 | 单发直射，速度适中 | 初始/通用 | 基础 |
| 扩散散弹 | 一次射出多枚扇形弹，弹道随连射变散 | 初始/中期 | 中 |
| 长程连射 | 高射速窄弹道，射程远 | 初始/中期 | 中 |
| 追踪弹幕 | 自动锁定最近目标，伤害较低 | 初始/后期 | 高 |
| 回溯弹 | 单发伤害低，命中留下记忆印记 | 初始/中期 | 中 |
| 棱镜弹 | 单发伤害低，可同时命中多个目标 | 初始/中期 | 中 |
| 穿甲弹 | 穿透 1 个敌人 | 补给箱 | 高 |
| 集束炸弹 | 抛物线投掷，落地爆炸 | 补给箱 | 中 |
| 激光枪 | 持续光束，伤害高，暴露时间长 | Boss 掉落 | 极高 |
| 散射榴弹 | 大范围爆炸，攻守兼备 | Boss 掉落 | 极高 |

### 武器衰减

武器有弹药计数，耗尽后退回上一槽位。
若上一槽位也为空，退回**脉冲弹**（保底武器，永不消失）。

## 角色能力系统

### 被动技能

每名角色有且只有一个被动，持续生效，无需主动释放。

| 角色 | 被动 | 效果 |
| --- | --- | --- |
| DeepSeek | 扩散之芯 | 散弹类武器弹道衰减速度减半 |
| Qwen | 远见 | 视野外的敌人提前 0.5 秒显示轮廓 |
| 豆包 | 粘性追踪 | 追踪弹伤害 +30%，锁定上限 +1 |
| GLM | 均衡律动 | 每消灭 20 个敌人回复 1 心（每关最多 1 次） |
| Kimi | 长上下文 | 每次命中敌人叠加一层「记忆印记」；集满 5 层释放，对已标记目标追加一次全额伤害 |
| Gemini | 多模态 | 棱镜弹可同时命中的目标数 +1（基础 3）；击杀目标时弹道分叉一次 |

### 炸弹技

每名角色有且只有一个炸弹技，有次数上限（初始 3 次，关卡可补充）。

| 角色 | 炸弹 | 效果 |
| --- | --- | --- |
| DeepSeek | 扩散冲击 | 以自身为圆心大范围爆炸伤害 |
| Qwen | 激光贯穿 | 垂直贯穿全屏光束，伤害中等 |
| 豆包 | 追踪母弹 | 释放多枚自动追踪弹 |
| GLM | 结界护盾 | 生成护盾吸收 3 次伤害，持续 5 秒 |
| Kimi | 上下文重放 | 回放最近 3 秒内已造成的伤害，对当前存活敌人结算 |
| Gemini | 四色折射 | 向四个方向同时射出棱镜弹幕 |

## 进度与存档

| 项 | 规则 |
| --- | --- |
| 关卡内状态 | 死亡后回到本关起点，**保留已拾武器**与得分 |
| 关卡通关 | 解锁下一关，累计记录最高分与通关次数 |
| 永久存档 | 最高分、已解锁关卡、设置项 |
| 存档位置 | 浏览器 localStorage（REQ-NFR-006） |

## 失败与重试

- 阵亡 → 1 秒死亡动画 → 0.5 秒停顿 → 回到关卡起点
- 全程 ≤ 3 秒（REQ-VIS-002）
- 重试**不重置**武器槽、得分、关卡内已触发的机关状态
- 难度选项（休闲/标准/硬核）影响敌人伤害与密度，不影响关卡结构
