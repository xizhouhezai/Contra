# 游戏策划文档（GDD）

本文档是 GDD 主体，聚焦**策划与表现层**：美术、音频、数值、流程、界面、发行。
玩法规则见 [玩法规格](/game/requirements/gameplay)，角色见 [角色规格](/game/requirements/characters)，
关卡见 [关卡规格](/game/requirements/stages)。

## 1. 美术方向

### 1.1 风格定位

**二次元立绘 + 序列帧精灵**。

- **立绘** —— 角色卡、选角界面、Boss 登场演出、结算画面使用高分辨率立绘，
  承载「宠物娘」的辨识度与性格表达。
- **序列帧精灵** —— 游戏内角色与敌人使用序列帧动画，帧率 12~15fps，
  配合屏幕抖动与残影做出「动起来」的感觉。

**分辨率基准**

| 资产 | 规格 |
| --- | --- |
| 角色精灵 | 32×48 px，按 2.5 倍显示 |
| 普通敌人 | 24×24 ~ 48×48 px |
| Boss 精灵 | 96×96 ~ 160×160 px |
| 角色立绘 | 1200×1600 px（含透明通道） |
| 场景背景 | 视口宽 × 2 层视差 |

**色彩策略**

场景使用**冷暖对冲**：环境偏冷（青、靛、墨），可交互元素与危险物偏暖（朱红、赭黄、橙）。
玩家在任何时刻都能凭颜色判断「什么能碰、什么会伤害」。

### 1.2 角色美术规格

| 角色 | 立绘要点 | 精灵帧数（待机/跑/跳/受击） | 主色 |
| --- | --- | --- | --- |
| DeepSeek | 蓝长发、鱼鳍耳饰、白女仆装 + 蓝拼接长裙 | 4 / 6 / 2 / 2 | 深海蓝 |
| Qwen | 橙白兽耳、蓬松毛发、黑 T 恤、程序员配饰 | 4 / 6 / 2 / 2 | 暖橙 |
| 豆包 | 圆润亲和的虚拟少女、红围巾、暖色调 | 4 / 6 / 2 / 2 | 暖橙 |
| GLM | 齐肩发、学者气质、灰绿米色、装备简洁 | 4 / 6 / 2 / 2 | 灰绿 |

形象依据见 [角色视觉参考](/game/requirements/character-references) ——

**立绘交付规范**

1. PNG 带透明通道，2 倍图（2400×3200）出图后缩至 1200×1600
2. 附表情差分 3~4 种（常态/得意/吃痛/认真）
3. 附「战斗姿态」与「立姿」两个版本
4. 命名规范：`char_<id>_<pose>_<exp>.png`

### 1.3 场景美术

三幕各 1 套主场景 + 1 套 Boss 场景，共 4 套。

| 幕 | 场景 | 主色 | 关键元素 |
| --- | --- | --- | --- |
| I | 破晓边境 | 暖橙 / 靛蓝 | 集装箱、锈蚀、晨雾、探照灯 |
| II | 硅基深处 | 青蓝 / 墨黑 | 服务器阵列、冷却液管、磷光、蒸汽 |
| III | 推理之巅 | 冷白 / 虹彩 | 悬浮台、符文、云海、无限镜面 |

**视差层数**：背景远景 / 中景 / 前景 / 前景虚化，共 4 层。

### 1.4 UI 视觉

沿用工作区文档站的 **Riso 技术手册**风格，与站点视觉统一：
暖纸白底、墨色字、朱红强调色、方形无圆角、衬线标题 + 等宽标签。

| 界面 | 要点 |
| --- | --- |
| 主菜单 | 大号衬线标题、印章式装饰、横排菜单项 |
| 选角界面 | 四栏卡片，每栏为角色立绘 + 属性条 + 武器图标 |
| HUD | 左上生命（心形序列）、右上分数与连击、右下武器槽 ×4 |
| 暂停菜单 | 半透明纸面遮罩，菜单项朱红高亮 |
| 结算界面 | 分数 / 命中率 / 用时三项，居中衬线数字 |

## 2. 音频设计

### 2.1 总体风格

**8-bit 芯片音乐**（主旋律）+ 采样音效（打击感）。
不使用任何受版权约束的曲目，全部自研或使用 CC0 音源。

### 2.2 BGM 清单

| 编号 | 曲目 | 风格 | 时长 | 使用场景 |
| --- | --- | --- | --- | --- |
| BGM-01 | 破晓 | 轻快摇滚 | 1:40 | 标题 / 选角 |
| BGM-02 | 港区疾行 | 高速电子 | 1:20 | 第 1~3 关 |
| BGM-03 | 审计 | 庄严机械 | 1:00 | 第 4 关 |
| BGM-04 | 硅底潜行 | 低频律动 | 1:40 | 第 5~7 关 |
| BGM-05 | 改写 | 不谐和电子 | 1:10 | 第 8 关 |
| BGM-06 | 推演 | 空灵合成器 | 1:50 | 第 9~11 关 |
| BGM-07 | 涌现 | 混沌电子 | 2:00 | 第 12 关 |
| BGM-08 | 终焉 | 主题变奏 | 1:30 | 通关 / 失败 |

### 2.3 音效清单

| 事件 | 音效 | 备注 |
| --- | --- | --- |
| 射击（8 种武器） | 各 1 | 每种武器音色可辨 |
| 命中敌人 | 短促打击 | 叠加轻微音高随机 |
| 玩家受击 | 下降扫频 | |
| 爆炸 | 低频噪声 | |
| 拾取武器 | 上行琶音 | 明确提示槽位变化 |
| 敌人死亡 | 碎裂噪声 | |
| 跳跃 | 短气音 | |
| Boss 阶段切换 | 低频冲击 + 静默 | 静默 0.5 秒制造紧张 |
| 结算 | 上行和弦 | |

### 2.4 混音规范

| 项 | 规格 |
| --- | --- |
| 主音量 | 0.8 |
| 音效峰值 | ≤ -6 dBFS |
| BGM 相对音效 | -12 dB |
| 爆炸类音效 | 最多同时 2 个，避免听觉疲劳 |

### 3.6 平衡校验

| 检查项 | 期望 | 实际设计值 |

| 单关期望得分 | 8,000~25,000 | 第 1 关约 3,000（教学关敌人少）✓ |

## 4. 游戏流程

### 4.1 流程图

```text
启动
  │
  ├─→ 标题画面 ──→ 选角 ──→ 关卡选择
  │       │            │          │
  │       │            │      ┌───┴───┐
  │       ↓            ↓      ↓       ↓
  │     设置/帮助    角色详情  关卡 1   继续(存档)
  │                                  │
  │                                  ↓
  │                            ┌──────────┐
  │                            │  进入关卡 │
  │                            └────┬─────┘
  │                                 ↓
  │                          ┌─────────────┐
  │                          │ 探索→遭遇→ │
  │                          │ 地形→Boss   │
  │                          └──────┬──────┘
  │                                 │
  │                    ┌────────────┴────────────┐
  │                    ↓                         ↓
  │              阵亡(≤3s)                   通关
  │                    │                         │
  │                    └──→ 回到关卡起点    结算 → 下一关
  │                                          │      │
  │                                          │   第12关 → 通关画面
  └──────────────────────────────────────────┴──────┘
```

### 4.2 关卡内分段结构

| 段 | 占比 | 内容 |
| --- | --- | --- |
| 探索段 | 40% | 无战斗或零星遭遇，熟悉地形与敌人 |
| 遭遇战 | 30% | 密集战斗，弹幕压力测试 |
| 地形谜题 | 20% | 需要新机制解题（弹墙/可破坏/移动平台） |
| Boss 战 | 10% | 关卡考核 |

### 4.3 幕间过场

第 4、8 关结束后播放幕间过场：30~45 秒的静态插画 + 文字 + 一段 BGM，
交代剧情推进（推理链的破裂与重组）。纯静态，不做动画，节省制作成本。

## 5. 界面清单

| 界面 | 说明 |
| --- | --- |
| 标题画面 | 项目 Logo、菜单（开始/选角/设置/帮助） |
| 选角界面 | 四栏角色卡 + 角色详情 + 确认 |
| 关卡选择 | 12 关网格，锁定状态，通关标记 |
| 游戏内 HUD | 生命、分数、连击、武器槽、Boss 血条 |
| 暂停菜单 | 继续/设置/重试/退出 |
| 设置 | 音量（主/BGM/音效）、难度、操作方案（触屏布局）、清除存档 |
| 结算 | 分数、命中率、用时、评价等级、继续/重试 |
| 通关画面 | 通关动画 + 总分 + 评价 |
| 触屏控制层 | 虚拟摇杆 + 射击/跳/炸弹按钮 |

**结算评价等级**

| 等级 | 条件 |
| --- | --- |
| S | 命中率 ≥ 90% 且剩余生命 ≥ 2 |
| A | 命中率 ≥ 75% |
| B | 命中率 ≥ 50% |
| C | 其他 |

## 6. 发行计划

### 6.1 平台

| 平台 | 首发 | 说明 |
| --- | --- | --- |
| Web（桌面） | ✓ | Chrome / Edge / Firefox / Safari |
| Web（移动浏览器） | ✓ | iOS Safari 15+ / Android Chrome 100+ |
| 原生 App | 后续 | 复用 `@contra/game-core`，更换表现层引擎 |

### 6.2 里程碑

见 [里程碑规划](/game/tasks/milestones)。

| 里程碑 | 目标 | 周期 |
| --- | --- | --- |
| M0 | 骨架与核心循环可玩 | 2 周 |
| M1 | 战斗系统与 4 角色成型 | 3 周 |
| M2 | 幕 I + 幕 II 关卡与 Boss | 4 周 |
| M3 | 幕 III 与终局 Boss | 2 周 |
| M4 | 美术音频完整替换 | 4 周 |
| M5 | 打磨、跨端、性能与发布 | 3 周 |

### 6.3 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 二次元立绘产能不足 | M4 延期 | 早期锁定风格与模板；优先 4 主角 + 4 Boss |
| 序列帧动画工作量超预期 | M4 延期 | 主角做全套，杂兵用 2 帧简化 + 位移补偿 |
| 移动端性能不足 | 体验降级 | 帧预算监控；粒子与阴影分级降级 |
| 规则层与表现层耦合 | 阻碍移动端 | 架构强制分离（见 [架构](/game/design/architecture)） |
