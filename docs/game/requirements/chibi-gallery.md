# Q 萌图库

各角色的 Q 版（约 2 头身）素材合集。
这些是社区二创，**版权状况不一，风险高于立绘** ——
仅作风格参考与备用素材，不得进入发行产物。

## 用途

| 用途 | 说明 |
| --- | --- |
| HUD 头像 | 血条旁的小头像，256×256 足够 |
| 选角界面 | 角色卡片的主视觉 |
| 表情贴纸 | 拾取武器、受击、通关等反馈 |
| 宣传素材 | 社交媒体与商店页 |
