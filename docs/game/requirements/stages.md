# 关卡规格

## 战役结构

```text
幕 I · 破晓边境    第 1~4 关   —— 基础机制，教会跑轰
幕 II · 硅基深处   第 5~8 关   —— 复合机制，考验配合
幕 III · 推理之巅  第 9~12 关  —— 高压对抗，逐级逼近终局
```

每幕 4 关，**第 4、8、12 关为幕 Boss 战**。

## 机制解锁表

新机制严格按幕引入，每关只引入一个。

| 关 | 新机制 | 说明 |
| --- | --- | --- |
| 1 | — | 教学关：无伤害敌人，只教移动/射击/跳跃 |
| 2 | — | 引入「弹墙」：子弹可反弹 |
| 3 | 平台跳跃 | 引入高低差与跳跃平台 |
| 4 | — | 幕 Boss：审计者（Claude 形态 I） |
| 5 | 追踪敌人 | 敌人会朝玩家移动 |
| 6 | 飞行敌人 | 空中单位，需仰射 |
| 7 | 强化装甲 | 敌人需多次命中或绕后 |
| 8 | — | 幕 Boss：改写者（Claude 形态 II） |
| 9 | 可破坏地形 | 部分平台可被炸开，暴露通路 |
| 10 | 移动平台 | 需等待时机跳跃 |
| 11 | 纵向关卡 | 摄像机纵向滚动 |
| 12 | — | 终局：GPT 双形态连续战 |

## 逐关详表

### 幕 I · 破晓边境

场景基调：黄昏工业港区，锈蚀集装箱、探照灯、油烟。暖橙与靛蓝配色。

#### 第 1 关 · 码头晨雾

| 项 | 内容 |
| --- | --- |
| 幕 | I |
| 场景 | 集装箱堆叠的栈桥，晨雾弥漫 |
| 长度 | 约 90 秒路程 |
| 敌人 | 巡逻兵（无伤害、教学用） |
| 教学点 | 移动 → 跳跃 → 射击 → 8 向瞄准 |
| 地形 | 平坦为主，仅一处低矮台阶 |
| 通关 | 抵达右侧出口 |
| 要点 | 敌人不造成伤害；拾取第一个脉冲弹教学武器槽 |

#### 第 2 关 · 锈铁回廊

| 项 | 内容 |
| --- | --- |
| 幕 | I |
| 场景 | 封闭的锈铁走廊，两侧管道 |
| 长度 | 约 2 分 30 秒 |
| 敌人 | 巡逻兵、哨兵（首次实弹） |
| 新机制 | **弹墙**：子弹碰到特定墙面反弹 |
| 地形 | 单层平面 + 两处弹墙掩体 |
| 补给 | 1 个扩散散弹 |
| 要点 | 哨兵子弹会被弹墙反弹，教会玩家利用掩体 |

#### 第 3 关 · 悬空栈道

| 项 | 内容 |
| --- | --- |
| 幕 | I |
| 场景 | 断裂的高架栈道，脚下是虚空 |
| 长度 | 约 2 分 30 秒 |
| 敌人 | 巡逻兵、哨兵、装箱工（搬箱掩体） |
| 新机制 | **平台跳跃**：高低差与可站立平台 |
| 地形 | 三层高低差，最大落差 3 格 |
| 要点 | 坠落即死，强制学习跳跃精度；装箱工可被击破露出后方通路 |

#### 第 4 关 · 审计者 · 幕 Boss

| 项 | 内容 |
| --- | --- |
| 幕 | I |
| 场景 | 审计大厅，巨型机械卷宗架 |
| 敌人 | 审计者（Claude 形态 I） |
| 招式 | 审计光束（横扫扇形）、条款锁链（地面光栅） |
| 阶段 | 单阶段；血量 50% 以下招式加速 |
| 掉落 | 激光枪 |
| 要点 | 教「Boss 阶段机制」——教学关的规则在此首次成立 |

### 幕 II · 硅基深处

场景基调：地下数据中心，服务器阵列、冷却液管廊、青蓝磷光。冷调配色。

#### 第 5 关 · 冷却管廊

| 项 | 内容 |
| --- | --- |
| 幕 | II |
| 场景 | 冷蓝管廊，蒸汽喷口周期性开启 |
| 长度 | 约 3 分钟 |
| 敌人 | 哨兵、追踪者（新）、蒸汽技师 |
| 新机制 | **追踪敌人**：会主动朝玩家移动 |
| 地形 | 管道掩体、周期蒸汽柱（推开玩家） |
| 要点 | 追踪者会持续逼近，需要用远程武器处理 |

#### 第 6 关 · 阵列机房

| --- | --- |

| 新机制 | **飞行敌人**：空中单位，需仰射 |
| 地形 | 高低机柜形成仰射通道 |

#### 第 7 关 · 熔炉区

| 项 | 内容 |
| --- | --- |
| 幕 | II |
| 场景 | 正在运行的熔炉区，热浪扭曲 |

场景基调：悬浮于云上的推理圣所，白玉与虚空，符文流转。冷白与虹彩配色。

#### 第 9 关 · 断裂推演

| 项 | 内容 |
| --- | --- |
| 幕 | III |

| 长度 | 约 3 分 30 秒 |

| --- | --- |

| 项 | 内容 |
| --- | --- |
| 幕 | III |
| 场景 | 无限镜厅，视野被无限延伸的镜像包围 |
| 敌人 | 语料（GPT 形态 I）→ 涌现（GPT 形态 II） |

## 关卡设计准则

1. **一个机制一段记忆** —— 每关只教一个新东西，让玩家能记住
2. **Boss 前必有缓冲** —— 第 4/8/12 关前不放补给，压迫感留给 Boss
3. **死亡点不集中** —— 难度平缓上升，不设单点劝退墙
4. **回退成本低** —— 关卡起点 3 秒内可达，鼓励重试而非放弃
5. **每关有 1~2 个隐藏要素** —— 隐藏通路、隐藏收集物，奖励探索
