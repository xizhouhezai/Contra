# 关卡规格

## 战役结构

```text
幕 I · 破晓边境    第 1~4 关   —— 基础机制，教会跑轰
幕 II · 硅基深处   第 5~8 关   —— 复合机制，考验配合
幕 III · 推理之巅  第 9~12 关  —— 高压对抗，逐级逼近终局
```

每幕 4 关，**第 4、8、12 关为幕 Boss 战**。

## 机制解锁表

新机制严格按幕引入，每关只引入一个。

| 关 | 新机制 | 说明 |
| --- | --- | --- |
| 1 | — | 教学关：无伤害敌人，只教移动/射击/跳跃 |
| 2 | — | 引入「弹墙」：子弹可反弹 |
| 3 | 平台跳跃 | 引入高低差与跳跃平台 |
| 4 | — | 幕 Boss：审计者（Claude 形态 I） |
| 5 | 追踪敌人 | 敌人会朝玩家移动 |
| 6 | 飞行敌人 | 空中单位，需仰射 |
| 7 | 强化装甲 | 敌人需多次命中或绕后 |
| 8 | — | 幕 Boss：改写者（Claude 形态 II） |
| 9 | 可破坏地形 | 部分平台可被炸开，暴露通路 |
| 10 | 移动平台 | 需等待时机跳跃 |
| 11 | 纵向关卡 | 摄像机纵向滚动 |
| 12 | — | 终局：GPT 双形态连续战 |

## 逐关详表

### 幕 I · 破晓边境

场景基调：黄昏工业港区，锈蚀集装箱、探照灯、油烟。暖橙与靛蓝配色。

| 项 | 内容 |
| --- | --- |
| 幕 | I |
| 场景 | 集装箱堆叠的栈桥，晨雾弥漫 |
| 长度 | 约 10 分钟；地图 12000px，纯跑约 67 秒，其余时间来自五段波次 |
| 敌人 | 五段波次共 12 只：巡逻兵为主，含飞行单位、固定炮台、冲锋兵各 1 |
| 波次 | ①单兵教学 ②两名夹击（门禁）③跨断口的空袭 ④仓库前混编（门禁）⑤门前冲锋 |
| 中段小 Boss | 码头工头：吊臂横扫 + 拖钩，血量 240，二阶段同一套招式加速 |

| 地形 | 三段地面 + 两处断口 + 十一处栈桥平台 |
| 通关 | 抵达右侧出口；两段门禁波未清则出口不开 |
| 要点 | 开局场上无敌人；两段门禁波 + 中段小 Boss 是时长的主要来源，地图本身只占约一分多钟 |

#### 第 3 关 · 悬空栈道

| 项 | 内容 |
| --- | --- |
| 幕 | I |

| 敌人 | 巡逻兵、飞行单位、固定炮台、冲锋兵 |

#### 第 4 关 · 审计者 · 幕 Boss

| 项 | 内容 |
| --- | --- |

| 场景 | 审计大厅，巨型机械卷宗架 |

#### 第 11 关 · 垂直井

| 项 | 内容 |
| --- | --- |
| 幕 | III |
| 场景 | 垂直向下的井道，摄像机随深度下降 |
| 长度 | 约 10 分钟（**900×9600 竖井**——全战役唯一按 y 推进的关卡） |
| 敌人 | 强化追踪者、飞行集群、镜像使徒、装甲单元、蒸汽口 |
| 新机制 | **纵向卷轴**：摄像机纵向滚动 |
| 地形 | 30 块左右交替的横台（340~380px 宽），中间留出 340~560px 的通道 |
| 中段小 Boss | **井道看守**（蜘蛛式多足机械攀在井壁，青色单灯） |
| 波次 | 6 段，**按 y 布置**（触发区是横跨井道的宽带，不是竖列） |
| 要点 | 视野受限，敌人从上方或下方进入；需用被动技能（Qwen 远见）预判 |

> **竖井的两条硬约束**（都由模拟发现，不是看出来的）：
> 1. **任何横台都不得横跨整个井道**。900px 的板子不是落脚点，是地板——落上去就再也跳不上去
>    （跳跃顶点 70px vs 台间距 280px），关卡不可通关而数据看起来完全正常。
> 2. **中段小 Boss 必须站在可站立的地面上**。悬在唯一横台下方 240px 的 Boss 玩家打不到，
>    触发会响、门禁会锁，但这场架永远打不起来。

> 「敌人种类」是**出现在该关波次里的 archetype 数量**，不是同屏数量。
> 同屏开火上限由幕决定（幕 I 1、幕 II 2、幕 III 3，见 maxConcurrentShooters）。

**总时长目标**：12 × 600s = **7200s = 120 分钟**，落在 REQ-VIS-001 的 100~120 分钟区间上沿。

口径说明：**全 12 关已统一按 10 分钟/关重做**，每关都是「波次 + 门禁 + 中段小 Boss」同一套配方，
不再是「幕 I 重做、幕 II/III 待办」的迁移中间态。第 11 关是唯一的形状例外：
它按 9600px 高、900px 宽的竖井铺开，而不是 12000px 宽，因为它的机制是向下推进。

时长分布：地图横向推进约占 60~70 秒（12000px ÷ 180px/s），其余 8~9 分钟全部来自
五至六段波次与一场中段小 Boss——这正是「长度来自要打完的仗，不来自更长的路」。

## 关卡设计准则

1. **一个机制一段记忆** —— 每关只教一个新东西，让玩家能记住
2. **Boss 前必有缓冲** —— 第 4/8/12 关前不放补给，压迫感留给 Boss
3. **死亡点不集中** —— 难度平缓上升，不设单点劝退墙
4. **回退成本低** —— 关卡起点 3 秒内可达，鼓励重试而非放弃
5. **每关有 1~2 个隐藏要素** —— 隐藏通路、隐藏收集物，奖励探索
6. **长度来自要打完的仗，不来自更长的路** —— 十分钟的关键是门禁波与中段小 Boss，
   而不是把地图拉长（REQ-STG-009 / REQ-STG-010）
