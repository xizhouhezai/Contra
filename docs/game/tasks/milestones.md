# 里程碑

## 总览

```text
M0 骨架          ──→ M1 战斗      ──→ M2 幕 I+II   ──→ M3 幕 III
  2 周               3 周              4 周              2 周
                                                    │
                                                    ▼
                                          M4 资产完整  ──→ M5 打磨发布
                                            4 周              3 周
```

总计 **18 周**（单人全职估算）。M0~M3 用灰盒美术，
M4 替换为最终美术音频 —— 玩法先跑通，资产后到位。

## 里程碑定义

每个里程碑有**明确的出口标准**。未达成不得进入下一里程碑。
这是 SDD 任务层的执行纪律。

---

## M0 · 骨架与核心循环

**周期**：2 周　**依赖**：无

**目标**

一个能跑起来的灰盒：角色能跑、能跳、能开枪打靶子，能从左走到右撞到终点。

**范围**

| 包含 | 说明 |
| --- | --- |
| `@contra/game-core` 包骨架 | 零依赖，类型与 World 骨架 |
| `@contra/game-platform` 接口 | Input / Storage / Audio / Lifecycle / Haptics |
| `@contra/game-web` 骨架 | Vite + Phaser 启动，Boot → Title → Stage 场景 |
| 固定步长循环 | 1/60s 逻辑更新 + 渲染插值 |
| 玩家实体 | 移动、跳跃、重力、地面碰撞 |
| 基础射击 | 8 向瞄准，单发直线子弹 |
| 灰盒关卡 | 一条 1600px 的平台 + 几个靶子 + 终点 |

**出口标准**

- [ ] 灰盒关卡可从头跑到尾，帧率稳定 60fps
- [ ] 规则层有 ≥ 20 个单测，覆盖移动、跳跃、碰撞、射击
- [ ] Biome 依赖边界检查通过（game-core 零依赖）
- [ ] `pnpm verify` 全绿

**追溯**：REQ-PLY-001 · REQ-PLY-002 · REQ-NFR-004

---

## M1 · 战斗系统与六角色成型

**周期**：3 周　**依赖**：M0

**目标**

六个角色各有独特打法，武器系统成立，敌人有威胁。

**范围**

| 包含 | 说明 |
| --- | --- |
| 武器系统 | 4 槽、8 种武器、弹药衰减、散射散布 |
| 角色系统 | 6 角色数据 + 被动 + 炸弹技 |
| 敌人系统 | 10 种敌人的行为状态机 |
| 伤害与无敌帧 | 阵营、无敌时间、死亡判定 |
| 空间哈希 | 碰撞优化 |
| 得分与连击 | 分数、连击、命中率 |
| 选角界面 | 四栏卡片 |
| 事件总线 | 规则层 → 表现层 |

**出口标准**

- [ ] 6 角色的手感可被明显区分（内部试玩确认）
- [ ] 8 种武器全部可用，散射散布、追踪锁定、穿透均正确
- [ ] 10 种敌人行为无卡死、无越界
- [ ] 规则层单测 ≥ 60 个，覆盖率 ≥ 80%
- [ ] 对象池生效，运行时零分配（子弹与粒子）

**追溯**：REQ-CHR-001 ~ 006 · REQ-PLY-003 ~ 009

## M2 · 幕 I + 幕 II 关卡与 Boss

**周期**：4 周　**依赖**：M1

**目标**

前 8 关可玩，两个 Claude 形态成型。

**范围**

| 包含 | 说明 |
| --- | --- |
| 幕 I 4 关 | 码头晨雾、锈铁回廊、悬空栈道、审计者 |
| 幕 II 4 关 | 冷却管廊、阵列机房、熔炉区、改写者 |
| 机制：弹墙 | 子弹反弹 |
| 机制：平台跳跃 | 高低差与平台 |
| 机制：追踪敌人 | 主动逼近 |
| 机制：飞行敌人 | 空中单位 |
| 机制：强化装甲 | 需绕后或穿甲弹 |
| Boss 系统 | 阶段状态机、招式调度、血条分段 |
| 审计者 Boss | 审计光束、条款锁链 |
| 改写者 Boss | 规则改写（重力反转）、文本风暴、最终校验 |
| 关卡选择界面 | 8 关网格 + 存档 |
| 结算界面 | 分数、命中率、用时、评价 |

**出口标准**

- [ ] 第 1~8 关全部可通关，无卡关点
- [ ] 5 种机制各自被正确触发与教学
- [ ] 2 个 Boss 阶段切换正确（视觉 + 音乐同步变化）
- [ ] 关卡数据完全由数据文件驱动，修改关卡无需改代码
- [ ] 每关目标时长与 GDD 设计值偏差 ≤ 20%
- [ ] 存档与进度正常

**追溯**：REQ-STG-001 ~ 005 · REQ-CHR-007 · REQ-PLY-008

## M3 · 幕 III 与终局 Boss

**周期**：2 周　**依赖**：M2

**目标**

12 关战役完整通关。

**范围**

| 包含 | 说明 |
| --- | --- |
| 幕 III 4 关 | 断裂推演、悬移回廊、垂直升塔、涌现 |
| 机制：可破坏地形 | 炸弹开路 |
| 机制：移动平台 | 水平与垂直移动 |
| 机制：纵向卷轴 | 摄像机纵向滚动 |
| 镜像使徒 | 复制玩家火力模式 |
| GPT 双形态 | 语料（3 残影分裂）→ 涌现 |
| 幕间过场 | 第 4、8 关后 |
| 通关流程 | 全 12 关战役 |

**出口标准**

- [ ] 12 关全部可通关
- [ ] 3 种新机制正确实现
- [ ] GPT 战 4 个阶段顺序正确，残影分裂与残影全灭逻辑正确
- [ ] 纵向关卡摄像机滚动无抖动、无卡顿
- [ ] 战役总时长落在 25~40 分钟区间

**追溯**：REQ-STG-006 ~ 007 · REQ-CHR-008 · REQ-VIS-001

## M4 · 美术与音频完整替换

**周期**：4 周　**依赖**：M3（可与 M3 部分并行）

**目标**

灰盒换成正式资产。

**范围**

| 包含 | 说明 |
| --- | --- |
| 6 角色立绘 | 1200×1600，3~4 表情差分 |
| 4 Boss 立绘 | 含形态差异 |
| 角色精灵 | 4 主角 × 4 状态 × 2~6 帧 |
| 敌人精灵 | 10 种 |
| Boss 精灵 | 4 形态 |
| 场景背景 | 4 套 × 4 视差层 |
| UI 视觉 | Riso 风格全套 |
| BGM 8 首 | 芯片音乐 |
| 音效 9 类 | 8 种武器 + 事件音效 |

**出口标准**

- [ ] 所有占位资源被替换完毕，无灰盒残留
- [ ] 立绘与精灵风格统一
- [ ] 每关有对应 BGM 且循环无明显断点
- [ ] 8 种武器射击音效可辨
- [ ] 首包体积 ≤ 8MB（REQ-NFR-003）
- [ ] 首屏加载 ≤ 5 秒（REQ-NFR-002）

**追溯**：REQ-GDD-001 ~ 003 · REQ-VIS-004 · REQ-NFR-002 ~ 003

## M5 · 打磨、跨端、性能与发布

**周期**：3 周　**依赖**：M4

**目标**

可发布版本。

**范围**

| 包含 | 说明 |
| --- | --- |
| 触屏控制 | 虚拟摇杆 + 按钮组 |
| 性能分级 | 高/中/低三档自动检测 |
| 设置菜单 | 音量、难度、操作方案、清除存档 |
| 暂停菜单 | — |
| 难度选项 | 休闲/标准/硬核 |
| 可访问性 | 减少闪烁、纯键盘可玩 |
| 平衡调整 | 依据试玩数据 |
| Bug 修复 | — |
| 发布 | 静态站部署 |

**出口标准**

- [ ] 移动浏览器完整可玩（REQ-NFR-009）
- [ ] 桌面端稳定 60fps（REQ-NFR-001）
- [ ] 30 分钟连续游玩内存增长 < 50MB（REQ-NFR-007）
- [ ] 崩溃率 < 0.5%
- [ ] 全部非功能需求逐条核对通过
- [ ] 部署完成并可公开访问

**追溯**：REQ-NFR-001 ~ 021 · REQ-GDD-004 ~ 006
