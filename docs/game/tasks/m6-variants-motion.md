# M6 · 形象变体与真实动作帧

**周期**：2026-10-21 ~ 2026-10-22　**依赖**：M5

**目标**

让角色从「一张会滑动的立绘」变成「有动作、能换形象、拿枪开火会动」的角色，
并把美术从灰盒占位换成真实素材。

**为什么单列一个里程碑**

M4 的原计划是「资产完整」，但 M4 交付时角色仍是一张静态立绘，
敌人是 48px 程序生成的色块。玩法能跑，画面不成立。
M6 补的是这一块，不改玩法规则。

## 过程中修正的真实缺陷

这些不是新功能，是原本就错的地方，在接入美术时暴露出来。

| 缺陷 | 表现 | 根因 |
| --- | --- | --- |
| 贴图键冲突 | 动作帧被静默丢弃，画面显示 192×48 灰块 | 旧占位图已占用 deepseek-idle，同名贴图第二个被丢弃 |
| 敌人原型靠猜 | act I 全部用错敌人或回落占位 | 渲染层取 id 的 '-' 前缀，但关卡 id 是 t1 而非 patrol-1 |
| 角色读错字段 | 进关卡即崩 | 读 target.box.height，而关卡数据是平铺的 height |
| 角色被背景吞掉 | 角色「看起来很小」 | 实测背景 107,139,119 vs 角色 103,134,121，仅差 4 级 |

**共同点**：这四处 tsc 全部通过，构建全绿，只有打开浏览器看运行时才发现。
