# 任务拆解

## 任务格式

```text
T-<里程碑>-<序号>  任务标题
  追溯      REQ-xxx / DES-xxx
  产出      具体交付物
  验收      可判定的完成条件
```

每个任务必须可独立指派、独立验收。

## 状态标记

- `[ ]` 未开始
- `[~]` 进行中
- `[x]` 已完成
- `[!]` 阻塞（附阻塞原因）

## M0 · 骨架与核心循环

### T-M0-01 建立 game-core 包骨架 `[x]`

- **追溯**：REQ-NFR-004 · ADR-0003
- **产出**：`packages/game-core/` 目录、package.json（零依赖）、tsconfig、vitest 配置
- **验收**：`pnpm --filter @contra/game-core test` 可运行；依赖检查脚本通过

### T-M0-02 定义核心类型与事件 `[x]`

- **追溯**：REQ-NFR-004
- **产出**：`src/data/types.ts`、`src/core.ts` 中的 `CoreEvent` 联合类型
- **验收**：类型被 `verbatimModuleSyntax` 正确处理；事件联合覆盖 shot/hit/death/pickup 等

### T-M0-03 实现固定步长循环 `[x]`

- **追溯**：REQ-NFR-001
- **产出**：`World.update(dt, input)`，固定 1/60s，单帧最多追 5 步
- **验收**：相同输入序列在 30fps 与 120fps 下产生相同结果（单测断言）

### T-M0-04 实现移动与跳跃 `[x]`

- **追溯**：REQ-PLY-001
- **产出**：`systems/Movement.ts`，含重力、平台碰撞、落地判定
- **验收**：跳跃弧线符合 GDD §3.1 数值；站立平台不穿透；单测覆盖

### T-M0-05 实现 8 向瞄准与射击 `[x]`

- **追溯**：REQ-PLY-002
- **产出**：`systems/Weapons.ts` 基础版、实体 `Bullet`
- **验收**：8 个方向均可射击；方向与移动解耦（前进中按后键可向后射）

### T-M0-06 搭建 Phaser 骨架与场景切换 `[x]`

- **追溯**：REQ-NFR-001
- **产出**：`packages/game-web/`，Boot/Title/Stage 三场景
- **验收**：Vite 开发服务器可启动；场景切换正常；规则层实体与精灵同步
- **验证结论**（2026-10-20）：`pnpm --filter @contra/game-web dev` 起服 315ms；
  无头 Chrome 经 CDP 实测 Boot→Title→Stage 逐场景进入；精灵每帧单向读 World，无回写；
  实测 60.3~60.7fps。事件桥只接 shot / stageCleared，其余七类留 M1（T-M1-09）。

### T-M0-07 灰盒关卡与终点判定 `[x]`

- **产出**：一条 1600px 灰盒平台 + 靶子 + 终点
- **验收**：可从头跑到尾触发通关事件
- **验证结论**（2026-10-20）：1600px 地面 + 2 块高台 + 4 靶子 + 右侧终点；
  浏览器实测按住 D 从 x=40 跑到 x=1504，stageCleared 触发 1 次（score=200），
  控制台输出 `[contra] stageCleared score=200`，界面显示 STAGE CLEARED。

## M6 · 形象变体与真实动作帧

**依赖**：M5　**详细记录**：[M6 里程碑](/game/tasks/m6-variants-motion)

M4 交付时角色仍是静态立绘、敌人是程序色块 —— 玩法能跑，画面不成立。
M6 补这一块，不改玩法规则。

### M6.1 形象变体

- `[x]` **T-M6-01** 建立形象目录（立绘 + 57 张 Q 萌梗图索引）
  - **实现**：`assets/looks.ts`（`looksFor` / `resolveLook`）+ `assets/chibi.ts`
  - **验收**：每个角色至少一个形象；未知 id 回落而非抛错

- `[x]` **T-M6-02** 选角界面按 Q 循环切换形象
  - **实现**：`CharacterSelectScene` 的 `cycleLook`，形象条显示「形象 Q 萌 2/21」
  - **验收**：DeepSeek 21 套形象可切换（浏览器实测）

- `[x]` **T-M6-03** 形象选择传递到关卡场景
  - **实现**：`StageSelectScene.init` 接收 `lookId`，`StageRequest` 透传
  - **验收**：选中的形象在关卡内实际显示

- `[x]` **T-M6-04** 梗图按需加载
  - **实现**：`import.meta.glob` 非 eager + `loadChibi`
  - **验收**：首包 3.15MB，未因 57 张梗图超预算

### M6.2 程序化动效

- `[x]` **T-M6-05** 纯函数动效模块
  - **实现**：`sprites/motion.ts`（`motionFor` / `breathScale` / `recoilOffset` / `hurtOffset`）
  - **验收**：14 个测试；呼吸 scale 恒 ≥ 1（否则角色下沉）

- `[x]` **T-M6-06** 由真实事件驱动
  - **实现**：`shot` 事件置 `secondsSinceShot = 0`；`playerHurt` 置 `hurtSeconds`
  - **验收**：动画不会与规则层脱节

- `[x]` **T-M6-07** 移动时停止呼吸、加入倾斜
  - **实现**：`motionFor` 中 `moveX !== 0` 时 `scaleY = 1`
  - **验收**：浏览器实测移动时旋转 0.06rad、缩放固定

### M6.3 自由瞄准

- `[x]` **T-M6-08** InputState 增加可选 aim 向量
  - **实现**：`data/types.ts` 加 `readonly aim?: {x, y}`
  - **验收**：7 个测试；缺省时行为与旧版逐字节一致

- `[x]` **T-M6-09** 保留八方向行为
  - **实现**：`aimVector` 优先读 aim，否则按 moveX/moveY
  - **验收**：输入为 -1/0/1 时仍只产生 8 个角度

- `[x]` **T-M6-10** 鼠标偏移转瞄准
  - **实现**：`StageScene.pollInput` 取指针世界坐标与角色差值
  - **验收**：实测瞄准角 -21.3°，非 45° 倍数

### M6.4 动作帧
