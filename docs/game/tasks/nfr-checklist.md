## 未通过项与未验证项的处理

### ❌ REQ-NFR-010 · WebGL 不可用时的提示

**当前行为**：Phaser `type: AUTO` 会回退到 Canvas 渲染器；若两者都不可用则白屏。
**待办**：在 BootScene 检测 `this.sys.game.renderer.type`，非 WebGL 时显示降级提示。
**优先级**：P1。不影响主流浏览器（2024 年后均支持 WebGL）。

### ⚠️ 需真实环境验证的 7 条

| 条目 | 需要什么 |
| --- | --- |
| 001 帧率 | 真机 1080p 连续 3 秒采样 |
| 002 冷启动 | Lighthouse 导航计时 |
| 004 覆盖率 | 安装 `@vitest/coverage-v8` 后跑 `--coverage` |
| 007 内存 | Chrome DevTools 堆快照对比（30 分钟游玩）|
| 008 跨浏览器 | Chrome/Edge/Firefox/Safari 各跑一遍 |
| 009 移动端 | iOS Safari / Android Chrome 真机 |
| 020 console | 运行时错误采集（可用 `window.onerror` 临时埋点）|

这些**无法用单测或构建断言替代**，标为未验证而非凑数通过。
